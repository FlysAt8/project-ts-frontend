# ProjectTS — Frontend

Федоров А.Д.

## Запуск проекта

Установка зависимостей - `npm install`

Запуск - `npm run dev`

После запуска приложение доступно по адресу: http://localhost:5173

## Экраны

`/login` — форма входа  
`/register` — форма регистрации  
`/confirm` — подтверждение почты (код `000000`)  
`/dashboard` — личный кабинет с вкладками:
 - Общие данные
 - Безопасность
